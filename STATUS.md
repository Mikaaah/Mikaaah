## Current notes

- **Towns & Kingdoms 3:** In active development. The CurseForge link points to the T&K3 project page; CurseForge approval is pending.
- **Loot Unidentified:** An alpha mod for Guild progression, loot and identifying gear. Its CurseForge page is pending approval; see the repository README and changelog for the current source and feature scope.
- **Resonant Arcana:** Spell design, balance and compatibility remain in development. Its CurseForge page is pending approval; see its README for current builds and limitations.
- **Flow Control:** The initial CurseForge project is published. See its README for supported behavior and current limitations.
- **UltraTerraForged × Alex's Caves:** Version 1.0.0 is available on CurseForge. Generation changes apply to new chunks; supported dependency versions are listed in the README.
- **UltraTerraForged × Streams Reflowing:** Downloads are available on CurseForge and GitHub. This adapter adds currents; it does not repair river terrain.

## Reporting an issue

Choose **Bug report**, **Feature request**, **Question / help**, or **Documentation issue** in the relevant repository. Towns & Kingdoms also has a **Player feedback** form. Required fields collect the affected version, environment and reproducible details appropriate to that project.

New reports receive their issue-type label and `needs-triage`. A maintainer removes `needs-triage` after review and uses the repository's existing labels for duplicates, requests for more information and other outcomes. Priority and release commitments are assigned after review, not by the form.

Search for an existing report first. Do not post tokens, passwords, personal documents, signatures or private server details.
