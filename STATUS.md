## Current notes

- **Towns & Kingdoms 3:** T&K3 is in development. Existing T&K2 downloads remain on the CurseForge project.
- **Resonant Arcana:** Spell design, balance and compatibility are still being developed. See the project README for current builds and limitations.
- **UltraTerraForged × Alex's Caves:** Version 1.0.0 is available on CurseForge. Generation changes apply to new chunks; supported dependency versions are listed in the README.
- **UltraTerraForged Streams Currents:** A GitHub download is available. This adapter adds currents; it does not repair river terrain.
- **LEVENLOOS Discord Bot:** Discord bot source and deployment notes are available. This overview does not monitor the live bot or promise uptime.
- **NEN 3140 Aanwijzingen:** Windows build instructions and an Actions workflow are available. Check the latest successful run for downloadable artifacts.

## Reporting an issue

Choose **Bug report**, **Feature request**, **Question / help**, or **Documentation issue** in the relevant repository. Towns & Kingdoms also has a **Player feedback** form. Required fields collect the affected version, environment and reproducible details appropriate to that project.

New reports receive their issue-type label and `needs-triage`. A maintainer removes `needs-triage` after review and uses the repository's existing labels for duplicates, requests for more information and other outcomes. Priority and release commitments are assigned after review, not by the form.

Search for an existing report first. Do not post tokens, passwords, personal documents, signatures or private server details. Use fictional data for document-generation examples.
