## 🏰 What I'm building

I'm the creator of **[Towns & Kingdoms](https://github.com/Mikaaah/TownsAndKingdoms)**, a Minecraft modpack project focused on Create-powered automation, exploration, magic, quests, and meaningful progression.

I also develop independent NeoForge add-ons, compatibility fixes, and the occasional non-Minecraft tool. Most of my projects start with: *"Surely I can make that work..."*
